# 企業名
ブックオフグループホールディングス株式会社

# 日時
## 発生日時
2026-10-04(日)～2026-10-06(火)
## 検知日時
2026-10-06(火)
## 公表日時
2026-10-09(金)

# タイムラグ
①発生→検知：0日
②検知→広報：0日

# 事故内容
子会社の会員管理システムに不正アクセス

# 損害
6,427,735件の会員データが流出  
※会員情報が外部に送信されたことを確認した会員データ件数 

# 漏洩した個人情報
・氏名  
・生年月日  
・性別  
・メールアドレス  
・電話番号  
・郵便番号  
・住所  
・パスワードのハッシュ値  
・ポイントカード番号  
・会員番号  
※クレジットカード情報等の決済情報は保有していないため流出していない。本人確認書類も会員管理システムに含まれていないため漏洩していない。

# 原因（公表内容）
（企業が発表した原因を要約）

# 影響範囲
ユーザー：最大638万件  
システム：ブックオフ会員管理システム  
サービス：国内ブックオフ事業セグメントの各サービス  

# 企業の対策・対応
不正アクセスに利用された経路の遮断を実施。会員に対し、2026年10月15日より順次案内メールを送信する予定。外部専門家の原因調査を実施中。  
個人情報保護委員会への報告及び警察への相談を実施。  
再発防止を策定中。 

# 自分の対策案（重要）
①権限の見直し：会員管理システムにアクセスできるAPIについて、過剰に権限が降られていないか確認をする。
