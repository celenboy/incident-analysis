# 事故内容
クロネコ代金後払サービスが不正アクセスを受ける

# 損害
- クロネコ代金後払サービスを利用する一部のユーザー情報が漏洩
- クロネコ代金後払サービスの加盟店の情報が漏洩
- クロネコ代金後払サービスの停止（サービス再開10/9金）

# 漏洩した個人情報
①クロネコ代金後払サービスユーザー情報 （約526万件、2018/10/1から2026/9/28）
- 氏名
- 住所
- 電話番号
- メールアドレス
- 商品明細
- 社内管理用情報

②クロネコ代金後払サービスを利用された一部ユーザーのお届け先情報（約5万件、2021/2/5から2026/9/28）

③加盟店情報 （約4100件）
- 加盟店名
- 加盟店コード

# 原因（公表内容）
調査中

# 影響範囲
- クロネコ代金後払サービスユーザー
- クロネコ代金後払サービス加盟店

# 企業の対策・対応
- 対象のサービスを停止
- 個人情報保護委員会に報告

# 自分の対策案（重要）
- 社外に公開しているアプリケーションの公開APIに関する見直し

# 自分の所感
- 第一報が情報漏洩が起こったという事実のみであったが、事実連携を優先し、早く広報していたのはよいと思った。
- お届け先情報はユーザーの情報とは性質が異なる（利用ユーザーとは別人の情報）なので、情報漏洩においてどのような扱いになるか要確認。
