# 事故内容
カーシェアリングサービス「タイムズカー」において、外部からの不正アクセスにより、タイムズカー会員の個人情報が外部に漏洩

# 損害
タイムズカー及びタイムズビジネスサービスの会員・退会済み会員で約660万件。
氏名、法人会員の所属部署名、住所、生年月日、電話番号、メールアドレス、免許情報、本人確認書類、パスワード、連携サービスID
※パスワードは復元できない形式、サービスIDは「JR西日本グループの会員サービスWESTER ID」等（計9件）

運転免許証画像などの本人確認書類が漏洩したアカウント数は160万件。
＜漏洩が確認されている書類＞
・運転免許証画像
・現住所確認書類画像
・学生証画像
・家族確認書類画像
# 原因（公表内容）
調査中

# 影響範囲
・タイムズカー会員及びタイムズビジネスサービス会員（退会済み含む）全ユーザー
・連携サービス先のシステム
※情報が不特定多数に公開された事実と当事象に起因する個人情報の不正利用の事実は確認されていない。

# 企業の対策・対応
9月26日7時25分までに、不正アクセスがあった経路について侵入を遮断する措置を講じた上で、攻撃元からの通信の遮断および遮断後のアクセス不能確認を完了。
個人情報保護委員会・警察への報告を実施。
原因及び影響調査のため外部専門機関によるフォレンジック調査を実施。
本人確認書類の漏洩が確認されたユーザーに対してメールで個別案内を実施。

# 自分の所感
発生から広報までの対応が非常に速い。ただ、大会済みのユーザー情報が洩れているのが疑問だった。大会済みのユーザー情報を利用して何かしているのであれば話が変わるが、基本リスクのため消去する運営にするべきなのでは。
